# Labs

Labs are **experimental capabilities** shipped behind explicit toggles.

## Why Labs exists
- Lets Sallie evolve quickly without breaking user trust
- Makes risk obvious (“this is experimental”)

## Examples of Labs features
- Wake word / always-listening mode
- Auto-triage email drafts
- Multi-step agent workflows
- Background monitoring routines

## Rules
- Labs must be opt-in
- Labs must have clear rollback (turn off, remove data)
- Labs must still write audit log entries
