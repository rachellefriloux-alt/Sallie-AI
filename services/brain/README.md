# services/brain/ — Python AI brain (the nine core systems)

**Canonical home for:** Sallie's mind. Per [`../../VISION.md`](../../VISION.md)
§2, this hosts the nine cooperating subsystems (Limbic, Memory, Monologue,
Synthesis, Agency, Dream Cycle, Degradation, Control, Convergence) plus
the Convergence onboarding flow.

## Run

```bash
cd services/brain
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Then in another shell:

```bash
curl http://localhost:8000/health
curl http://localhost:8000/ready
curl http://localhost:8000/convergence/phases
```

## Test

```bash
cd services/brain
python -m pytest                # 62 tests
```

## Local dev stack

The full local stack (brain + knowledge + Qdrant + Postgres + Redis + MinIO)
comes up via the compose file at `services/brain/docker-compose.yml`. See
`../../docs/CONFIGURATION.md` for the env vars each service consumes.

## Convergence

The 40-question Convergence flow (5 protocols Q1–Q29 + Visage Q30–Q40)
lives under `app/convergence/` per ADR 0006. The data is in
`app/convergence/data/{canonical_29,visage_11,phases,questions}.json`.
