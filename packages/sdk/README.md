# `@sallie/sdk`

Typed brain client. Wraps the OpenAPI spec generated by `services/brain`
into an ergonomic SDK consumed by every Sallie client
(`apps/mobile`, `apps/web`, `apps/desktop`).

> Phase 1, item 28 of the build plan. Phase 6, item 55 adds the skill
> registry under `@sallie/sdk/skills`.

## Status

Scaffolded in Phase 0.6. The real client (request/response types,
WebSocket helpers, retry policy, auth interceptor) is generated from
the brain's OpenAPI spec in Phase 1.

## Sources to merge here

Per the build plan, this package is filled in by porting from the
imported repos in `legacy/`. Nothing in `legacy/` is modified — code
is **promoted** out of it into this package.

| Source                                          | What to take                                          |
|-------------------------------------------------|-------------------------------------------------------|
| `services/brain/` OpenAPI spec (Phase 1)        | Generated types and request methods                   |
| `legacy/Sallie/sallie/` (130+ Next.js routes)   | Request/response shapes, retry & auth conventions     |
| `legacy/sallie-project/src/api/` and `services/`| Typed client patterns, error envelope, pagination     |
| `legacy/app/` production auth flow              | JWT refresh interceptor, device-pairing handshake     |
| Phase 6 — Digital Progeny v5.4.x skill manifest | `@sallie/sdk/skills/` tool-calling registry           |

## Quality bar

Per [ADR 0005](../../docs/architecture/0005-quality-bar.md): TS strict,
